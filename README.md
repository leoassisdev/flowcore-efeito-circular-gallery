## Como instalar

1. **Crie src/components/CircularGallery.tsx** Copie o conteúdo de `src/CircularGallery.tsx` e `src/CircularGallery.css` deste repositório. Esse efeito também tem CircularGallery.css: crie ao lado.
2. **Use na página**

   ```tsx
   <CircularGallery items={[{src, label}]} bend={1} />
   ```
